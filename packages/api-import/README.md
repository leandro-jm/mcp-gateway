# @mcp-gateway/api-import

Imports Postman collections, HAR files, cURL commands and OpenAPI documents, detecting the format and building an OpenAPI document (ADR-014).

Pure package: no I/O (enforced by ESLint).

Part of the [mcp-gateway](../../README.md) monorepo; internal and not published to npm. Licensed under [Apache-2.0](../../LICENSE).
