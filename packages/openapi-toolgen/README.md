# @mcp-gateway/openapi-toolgen

Turns OpenAPI 3.x / Swagger 2.0 operations into agent-friendly tool definitions; also normalizes schemas, infers metadata and diffs tool sets for drift.

Pure package: no I/O (enforced by ESLint).

Part of the [mcp-gateway](../../README.md) monorepo; internal and not published to npm. Licensed under [Apache-2.0](../../LICENSE).
