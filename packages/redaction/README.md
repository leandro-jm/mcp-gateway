# @mcp-gateway/redaction

PII redaction engine: value and field detectors (CPF, CNPJ, PIS, CEP, email, phone, card, IBAN, …) and mask/hash/drop/tokenize strategies.

Pure package: no I/O (enforced by ESLint).

Part of the [mcp-gateway](../../README.md) monorepo; internal and not published to npm. Licensed under [Apache-2.0](../../LICENSE).
