# @mcp-gateway/testkit

Test utilities: fake HR upstream with synthetic data, OpenAPI/Postman fixtures, Testcontainers helpers and synthetic tool catalogs.

Run the fake upstream with `pnpm dev:upstream` (port 4010). All generated data (names, CPFs, emails) is synthetic.

Part of the [mcp-gateway](../../README.md) monorepo; internal and not published to npm. Licensed under [Apache-2.0](../../LICENSE).
