# @mcp-gateway/admin-ui

React + Vite admin console: sources, tools, policies, virtual servers, tokens, composer and observability dashboards, in `en`, `pt-BR` and `es`.

Run with `pnpm --filter @mcp-gateway/admin-ui dev` (port 5180, proxies to the gateway on 4000). E2E: `pnpm --filter @mcp-gateway/admin-ui test:e2e` (Playwright).

Part of the [mcp-gateway](../../README.md) monorepo; internal and not published to npm. Licensed under [Apache-2.0](../../LICENSE).
