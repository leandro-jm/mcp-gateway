# @mcp-gateway/crawler

BullMQ worker that discovers APIs (OpenAPI and other import formats), generates agent-friendly tools, registers them disabled and detects drift.

Run with `pnpm --filter @mcp-gateway/crawler dev`. Configuration: [`.env.example`](.env.example).

Part of the [mcp-gateway](../../README.md) monorepo; internal and not published to npm. Licensed under [Apache-2.0](../../LICENSE).
